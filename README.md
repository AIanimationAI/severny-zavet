## Установка

1. На странице выпуска скачайте **Severny-Zavet-2026-10-18.zip**. Автоматические архивы **Source code** не содержат игру.
2. Распакуйте ZIP целиком в отдельную папку, например `C:\Games\SevernyZavet`.
3. Откройте вложенную папку **Северный Завет — сборка 2026-10-18** и запустите **Запустить Северный Завет.cmd** или **h3era HD.exe**.
4. Разрешение настраивается через **HD_Launcher.exe**. Для запуска без HD используйте **h3era.exe**.
5. Начните новую партию, чтобы применились новые стартовые навыки героев.

Не накладывайте архив на HotA или другую сборку. Личные сохранения, журналы и тестовые скрипты выдачи навыков в архив не включены.
